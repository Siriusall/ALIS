# ALIS

ALIS 是一个面向沪深 A 股的个人投资研究与模拟交易系统。

系统围绕数据、研究、模型、策略、组合、模拟执行和复盘构建完整闭环，目标不是简单地给股票打分，而是让每一次投资判断都有可靠数据、明确逻辑、风险约束、退出条件和可回放的决策证据。

> ALIS 当前用于研究与模拟交易，不接入实盘，不承诺投资收益。

## 核心理念

ALIS 使用多类证据共同形成判断：

- **叙事与事件**解释潜在收益空间。
- **资金持续性**验证市场认可程度。
- **价格结构与相对强度**决定交易时点。
- **基本面、估值与盈利预期**决定持有期限。
- **市场状态与组合风险**决定整体风险预算。

任何单一叙事、单日资金流或单一模型都不能独立触发交易。系统必须同时考虑数据可信度、预期收益、尾部风险、相关性、流动性、交易成本和退出条件。

## 系统闭环

```text
外部数据
→ 原始数据留痕与点时可用性
→ 标准化、质量检查与数据冻结
→ 市场、公司、行业、公告、主题和预期研究
→ 模型识别信号
→ 策略总控决定买入、加仓、减仓、退出或持有
→ 组合优化决定目标权重
→ 模拟执行与成交记账
→ 决策回放、收益归因与策略复盘
→ 产生下一轮模型和策略改进候选
```

## 主要功能

### 数据中台

- 沪深 A 股行情、估值、财务、公告、股东、指数和 ETF 数据。
- TuShare、交易所与网页备用源的分层采集。
- 原始响应留痕、点时可用性和来源追踪。
- 数据补全、断点续跑、质量检查和失败恢复。
- 最新交易日数据完整性硬门，避免不完整数据进入决策。

### 投资研究

- 市场状态、情绪与风险环境分析。
- 公司财务质量、成长、现金流、估值和风险研究。
- 行业状态、公告事件、主题叙事和盈利预期跟踪。
- 股票池准入、迁移和淘汰。
- 可证伪的投资逻辑卡片、证据更新和失效条件。

### 模型与策略

- 市场状态识别。
- 中期股票排序。
- 资金持续性、龙头、事件影响评估和叙事生命周期模型。
- 统一策略总控，将模型信号转化为买入、加仓、减仓、退出、持有或防御切换。
- 策略动作合同、策略版本、候选验证、审批、晋升和回退治理。

### 组合与风险

- 基于预期收益、经验 CVaR、相关性和交易成本的组合优化。
- 换手、拥挤度和集中度软惩罚。
- HRP 风险分散降级方案。
- 现金、停牌、涨跌停、流动性、最小交易单位和不可超卖等安全约束。
- 股票机会不足时，在合格 ETF 和防御资产中寻找替代配置。

### 模拟执行与复盘

- 正式调仓计划、版本、数据截止日和计划执行日。
- 模拟成交、手续费、滑点和 FIFO 成交批次。
- 决策证据冻结、完整性校验和历史回放。
- 持仓、组合走势、调仓原因和风险贡献展示。
- 市场、行业、选股、仓位和执行成本归因。
- 人工复核和策略改进任务。

## 当前阶段

ALIS 已经形成从数据到模拟成交和复盘的主要产品链路，当前重点是进一步证明策略有效性并完成自优化闭环：

- 历史逐交易日策略重放。
- Purged walk-forward 与跨市场状态样本外验证。
- 复盘结果自动生成 Challenger 策略候选。
- 资金、龙头、事件和叙事模型更深入地影响策略动作。
- 基于历史成交、持仓、现金和费用的真实账户净值重建。
- 行业经营、一致预期、主题暴露和公告抽取研究深度提升。

## 项目边界

ALIS 是个人投资研究工具，不是证券投资建议服务，也不对任何收益结果作出保证。模型输出、回测结果和模拟成交均可能受数据质量、市场环境变化、交易成本和模型失效影响。
