# ALIS 计划书实现矩阵

> 本文件按《ALIS长线投资系统工程计划书》逐项验收。`接口存在`不等于`生产完成`；只有数据、计算、持久化、解释、前端下钻和测试同时具备才标记完成。

## 后端里程碑

| 里程碑 | 计划书完成定义 | 当前判断 |
|---|---|---|
| M0 / P0 | 数据资产、全量补全、增量、质量、失败队列、空间保护 | 基础已接入；长期正确性、SLO和空间保护未完成 |
| M1 / P1 | 风险、分类、行业模板、公告、多维状态 | 仅零散数据与原语；正式研究闭环未完成 |
| M2 / P2 | 状态、情绪、主题、预期、动态门控 | 模型原语存在；真实观测、持久化和门控未贯通 |
| M3 / P3 | 逻辑、估值、股票池、组合、状态机、快照复盘 | 模拟执行部分存在；投资逻辑和决策快照域缺失 |
| M4 / P4 | 版本、样本外、漂移、降级、LLM证据、Champion/Challenger | 部分存在；长期治理和冻结验收集未完成 |

## 固定实施顺序

1. 先重构前端信息架构，所有模块均显示真实状态，不用假数据填空。
2. P1先建立可解释研究事实模型，所有分数返回分项、权重、证据、缺失项和置信度。
3. P2只允许读取带来源和可用时间的真实观测；数据不足时明确降级，不生成伪状态。
4. P3将投资逻辑、估值、组合动作和决策快照持久化贯通。
5. P4最后开放自动调优；未通过样本外、漂移和组合门控不得晋升。
